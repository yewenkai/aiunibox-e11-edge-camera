# 项目当前状态

本次源码收口日期为 2026-10-14。目标仍是 AIUniBOX-E11 / RK3566 的局域网摄像头与看护工具。仓库只保存研究源码、测试和必要配置，不分发 APK、模型权重、厂商程序、家庭配置或现场诊断。

## 保留的功能

- 摄像头端 1.9.3：HTTP 8080 控制、WebRTC / RTSP / 同源 HLS、时间戳、水平云台与隐私模式。
- 按观看、快照和视觉守护需求采集；无需求 30 秒后待机。隐私与手动暂停优先，远程访问不能绕过。
- 七路可控灯默认关闭，观看者变化不自动亮灯；相机会话重建后恢复用户手动选择。
- 本地哭声检测、动作分析、事件短片，以及可选的 NPU / Pose / 面部可见性补强。模型和 RKNN 运行库由使用者自行取得，缺失时按功能降级。
- 电视接收端 1.1.3：原生 WebRTC 与手动 RTSP 备用模式、遥控器操作；首次自行设置设备地址，不内置家庭地址。
- 原有摄像头 Home Assistant 集成 0.1.2：供 HA 访问摄像头和硬件控制，与已取消的中屏语音控制方向分开。

网页对讲和设备端 HTTPS 已移除，本地哭声检测仍保留。独立语音管家实验已撤回，Android 工程只包含 `app` 和 `tv`，不再包含唤醒词、中文识别或语音播报模块。
